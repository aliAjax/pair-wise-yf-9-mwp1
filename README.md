# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 规则修订留痕

对规则的**新增、移除、改正**都必须填写「修订人」和「原因」，缺任一项整次操作被拒绝，规则保持原样，也不会产生版本。

- 详情页底部的「修订记录」按时间倒序列出每个版本（版本号、动作、修订人、时间、改动内容、原因）。
- 点击「查看版本」可在当前详情面板内查看该版规则快照（只读，不新增页面）。
- 在历史版本视图点击「回滚」并填写回滚操作人与原因后，只把该版的规则内容复制为一个**新的回滚版本**；游戏名称、人数等信息不变，所有旧版本继续保留。
- 顶部收藏数、遗忘点统计与规则内容同源，所有修订（含回滚）立即同步，并随 localStorage 存档持久化，刷新后仍在。
- 升级前的旧存档首次打开时会自动补录一个初始版本，现有规则不丢失。

## 代码结构（三个业务文件）

- `rules.js` — 规则处理：规则分类、内容快照，以及新增/移除/改正的业务校验（不碰界面与存档）。
- `store.js` — 版本存储：localStorage 读写、版本只增追加、旧存档迁移、回滚生成新版本。
- `app.js` — 界面：列表/统计/详情渲染与事件编排，调用前两个文件完成实际操作。

无构建步骤、无外部依赖。
