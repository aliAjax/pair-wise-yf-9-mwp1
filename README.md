# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问，无需安装任何依赖。

## 规则修订留痕

每次**新增、移除或改正**规则都必须填写：

- **修订人**：谁改的
- **修订原因**：为什么改

两项（以及规则内容本身）缺任一项都会整次拒绝——弹窗提示错误，规则内容不变，也不会产生空版本。

详情页可查看每个历史版本的完整规则内容；任意旧版本都可以**回滚**：

- 回滚只恢复该版本的四类规则内容，桌游名称、人数、时长等信息不动；
- 回滚本身也是一次修订，需要填写修订人与原因，并生成一条新的“回滚”版本；
- 被回滚到的版本、以及中间的所有版本都继续保留，可以再次回滚到任意一版；
- 当前版本不允许重复回滚。

列表顶部的收藏数、规则总数与本地存档一起保存在 `localStorage`，刷新页面后规则与版本历史仍在；旧版存档首次打开会自动补录初始版本。

## 文件结构

三个业务文件各司其职，不引入任何第三方依赖：

- `rules.js` — 规则处理层：规则快照、修订人/原因校验、新增/移除/改正的规则计算（校验不过返回错误，不动原数据）。
- `versions.js` — 版本存储层：版本的生成与追加、回滚、`localStorage` 读写与旧存档迁移。
- `ui.js` — 界面层：列表/详情渲染、修订弹窗、版本查看与回滚弹窗、所有事件交互。
